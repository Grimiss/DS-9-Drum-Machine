# GRIMISS DS-9 Drum Machine

Nine-voice analogue-modelled drum machine and sample sequencer for Windows.

Status: design specification; implementation not started.

Key features: nine permanently visible lanes, 16 steps per lane, independent lane lengths (1–16), combined open/closed hi-hat, analogue or WAV sample voice per lane, four pattern memories, tempo and swing.

Development documentation will be prepared on the `development` branch. The GMC-9000 sampler is a separate instrument with optional future synchronization.
